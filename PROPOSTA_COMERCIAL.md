# Proposta Comercial

## Sistema Agregador de Leilões de Imóveis

---

## Sobre o Sistema

Plataforma completa para agregação e exibição de imóveis em leilão de múltiplas fontes, incluindo bancos e leiloeiros de todo o Brasil.

### Principais Funcionalidades

- **Agregação Automática** de imóveis de 10+ fontes
- **Painel Administrativo** completo para gestão
- **Filtros Avançados** por estado, cidade, tipo, preço
- **Atualização Diária** automática via scrapers
- **Design Responsivo** para desktop e mobile
- **Sistema de Favoritos** para usuários
- **Geração de Leads** com formulário de contato

### Fontes Integradas

| Bancos | Leiloeiros |
|--------|------------|
| Caixa Econômica Federal | Sodré Santoro |
| Banco do Brasil | Mega Leilões |
| Santander | Pestana Leilões |
| Itaú | VIP Leilões |
| Bradesco (Resale) | Portal Zuk |

### Base de Dados Atual

- **34.354 imóveis** cadastrados
- **2.608 imóveis** com fotos
- Cobertura em **todos os estados** do Brasil
